# Aethrix Creatives Premium Agency Landing Page

## Overview
Build a polished single-page agency experience that turns the supplied Aethrix identity and presentation content into a modern, conversion-focused website. The page will use the navy brand world, luminous emerald-to-indigo accents, restrained glass surfaces, and the supplied dark logo throughout.

## What will be built
- A sticky navigation bar with prominent brand identity, section links, mobile menu, and project CTA.
- A strong first screen featuring “Where Ideas Become Impact,” the four capability badges, clear calls to action, and a visual expression of the Aethrix peak mark.
- A filterable services matrix covering all five requested disciplines and their included deliverables.
- A three-level workflow section with an interactive level selector and clear phase progression.
- An interactive industries grid for the six requested audience groups.
- A six-part “Why Aethrix” section based on the supplied presentation.
- A complete three-step scope inquiry form with service selection, budget/timeline, contact details, validation, progress, back/next controls, and a clear success state.
- A substantial footer with brand, mission, service directory, social links, and copyright.

## Visual direction
- Deep midnight navy foundations with high-contrast typography and luminous emerald, cyan, indigo, and violet accents.
- Distinctive editorial typography, subtle grid/light effects, crisp borders, restrained glass panels, and purposeful motion.
- Use the supplied dark Aethrix logo as the primary brand asset and prepare a matching favicon.
- Responsive layouts for desktop, tablet, and mobile, with accessible focus states and reduced-motion support.

## Technical details
- Implement the page at `/` using the existing TanStack Start and Tailwind setup.
- Add small focused React components for navigation, services, workflow, industries, value drivers, inquiry form, and footer.
- Use existing shared button and form controls where appropriate.
- Keep inquiry data in the browser for this version; submission will show a polished confirmation without sending data externally.
- Add unique page title, description, Open Graph metadata, and Twitter card metadata.
- Verify the finished page in a real browser at desktop and mobile widths, including tabs, navigation, and every form step.
